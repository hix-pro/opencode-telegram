# Code of conduct

This project should be a place where people can report a bug or propose a
change without being harassed, dismissed, or talked over.

## Expected behavior

- Be direct about code and kind about people.
- Assume good faith, but be precise about evidence, versions, and reproduction
  steps.
- Respect privacy: never publish another person's tokens, logs, chat ids,
  filesystem paths, or private messages.
- Accept that security-sensitive changes may need a slower review and a
  smaller default surface.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, publishing private data, and
deliberately disruptive or bad-faith participation are not welcome. Security
research is welcome when it follows the private reporting process in
[SECURITY.md](SECURITY.md).

## Scope

This applies to issues, pull requests, discussions, and any project space.
Maintainers may edit or remove content and may temporarily or permanently ban
participants for violations.

## Reporting

For a conduct concern, contact the maintainer through the GitHub profile linked
from this repository. Do not open a public issue containing private details.
Reports will be handled as confidentially as the platform allows.
